  - `dev/emi/emi/api` from [EMI](https://github.com/emilyploszaj/emi), licensed MIT
  - `me/shedaniel/rei` from [Roughly Enough Items](https://github.com/shedaniel/RoughlyEnoughItems), licensed MIT
  - `mezz/jei/api` [Just Enough Items](https://github.com/mezz/JustEnoughItems), licensed MIT
- Platform Fluid APIs:
